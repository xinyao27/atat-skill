# AtAt skill: `atat`

This repository is AtAt's skill: it teaches Claude Code, Codex, Cursor, OpenCode and
any other agent that reads skills how to use the `atat` command on this Mac — screenshot the
screen, a window, an area or a whole scrolling page; read clipboard history and the Finder
selection; film a demo video of an app; or hand a task to AtAt's own agent. It is also a
Claude Code plugin and marketplace, so both install paths read this one repository.

Requires macOS 15 or later and the [AtAt app](https://atatapp.com/download). The app is free; the
agent-facing commands need no account.

## Install

1. Install the AtAt app on macOS via Homebrew or direct download:
   `brew install --cask xinyao27/tap/atat`
   or download from [https://atatapp.com/download](https://atatapp.com/download).
2. Open AtAt → Settings → Agent and click **Connect** under **atat CLI** (or run `atat skill install`).
3. Any agent that reads skills or plugins — Claude Code, ChatGPT, Codex, Cursor, OpenCode — now knows how to use it.

Check it worked:

```bash
atat status
```

## Install as a Claude Code plugin

`.claude-plugin/` in this repository holds the marketplace and the plugin manifest, and the
plugin's `source` is this repository root, so one command each:

```bash
claude plugin marketplace add xinyao27/atat-skill
claude plugin install atat@atat
```

The plugin carries the same skill.

## What is in here

| File | What it is |
| --- | --- |
| `SKILL.md` | the AtAt command skill |
| `skills/atat/SKILL.md` | the AtAt command skill in Claude Code plugin layout |
| `skills/atat-memory/SKILL.md` | the AtAt Memory skill |
| `.claude-plugin/plugin.json` | the plugin manifest: name, version, author |
| `.claude-plugin/marketplace.json` | the marketplace manifest, whose one plugin is this repository root (`source: "./"`) |

This repository is generated by `tools/scripts/export-public-skill.mjs` in the AtAt repository, and `SKILL.md` is a copy of the one the app ships. To change the skill, change its source:

```bash
# in the AtAt repository
pnpm publish:skill
```
